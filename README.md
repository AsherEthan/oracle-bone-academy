# 字在 · 甲骨文小展馆

逛真实字形，参看著录、目录标签与相关文献，提供辅助判断的材料，不替字形下定义，不把古字与现代字直接画等号。技术核对记录按需展开，不把资料核查流程做成访客的浏览负担。

## 启动

需要 Node.js 22+（开发环境为 Node.js 24 / Windows）。

```bash
npm install
npm run dev         # http://localhost:5173
npm run build       # 类型检查并生成 dist/
npm run preview     # http://localhost:4173
npm test            # 字头归并、来源对应、图片完整性和收藏兼容
npx playwright install chromium
npm run test:e2e    # 桌面与手机的真实浏览器测试
```

使用 `npm run build`。构建脚本异步清理输出目录，避开本机 Node.js 24 / Windows 下同步删除目录时的原生崩溃。

## 浏览体验

- **全部字库**：「输入线索」模式每页 48 个来源字头，「按图找字」模式每页最多 96 幅实际来源展图，以字头号标识；现代字不再作为大标题，也不在字形旁展示普通话拼音。
- **检索**：来源标签、现代检索词、已有普通话拼音、繁简别名、字头号、字例号、著录及参考资料主题。搜索关联不是古今对应或古音判定，结果中明确提示。
- **有参考材料**：12 条记录附香港中文大学漢語多功能字庫的相关字条链接、讨论主题与引辞边界。撤下原有定义式标题、本站释义及引导性观察说明，不把资料改写成答案。
- **未标汉字**：没有可直接显示的来源标签时，仍展示真实图片与字头编号，不猜现代字、读音或含义。这不等于学界“尚未释读”的判定。
- **同头字例**：按小學堂原生字头号分组供切换；这是来源目录的组织方式，不是本站对字形分合或全部异体的判定。
- **拾字簿**：收藏使用稳定来源 ID；旧的现代字收藏仍兼容。有对应记录的旧收藏自动关联到来源字头，没有的保留在折叠记录里，不展示空卡片。
- **材料与核对记录分开**：详情先提供这幅字例的编号、著录、来源入口及字头层级的目录标签；标签与参考材料均标明归属。图片许可、下载地址和文件哈希另行折叠。收藏只在本地浏览器保存，无账号、不上传。

显示的目录标签仅取导入记录的原始标签，不把本站为搜索增加的繁简别名、旧现代标签冒充来源字段。参考材料与原配图的引辞边界保留；切换到其他字例时，不把原配图所附的材料说明移接给它。

## 怎么找字

- **手上有文字线索**：在「输入线索」里查现代汉字标签、已有拼音检索词、著录或字例号。可直接点示例标签；例如 `水`、`shui`、`合34165`、`45.E538`。精确字头号、字例号和目录标签优先，卡片标明匹配的是标签、现代别名、著录还是参考材料，不将检索关联当作古今字等同。
- **只记得图形，不知道叫什么**：切到「按图找字」，用每页最多 96 幅原图的紧凑图墙浏览；可按展图「偏高 / 偏宽 / 近方」粗筛，再点图放大。也能叠加「未标汉字」筛选和收藏。没有用字义、构件或补绘字形给未知条目分类。
- **拿着来源编号来找**：字例号支持大小写及点、空格、连字符分隔；`字头 142`、`#142` 会优先定位来源字头 142。搜索命中其他字例时，预览与详情直接打开那幅图，不把默认图的参考材料移给它。
- **查不到时**：可清除限制，或在「全部字库」里重查。未命中不等于该字形不存在；图墙也只是人工看图的辅助入口，不是上传图片识字或同字判定。

轮廓来自原始 PNG 中可见墨迹的包围框，宽高比大于 1.25 为偏宽、小于 0.8 为偏高，其余为近方。仅计算导航元数据，不修改图片；同组的其他字例可能有不同轮廓。`visual-index.json` 与当前来源输入摘要及实际展图编号绑定，测试会拒绝过期索引。维护者更新字例后，可在安装 Pillow 的 Python 环境中重新生成；网站运行及 npm 构建不依赖 Python：

```bash
python -I scripts/build-visual-index.py "<项目根目录>"
node scripts/smoke-finding.mjs "<项目根目录>" http://127.0.0.1:4180
```

## 收录数量与边界

当前实际接入 **4,818 个来源字头、5,211 幅不同编号的字例**，其中 **3,422 个字头未标通用汉字标签**。图片已本地保存；同一来源字头下的多幅字例不重复计字头，同一编号的不同分辨率图片也不重复计字例。

**“约 4,500 个单字”是常见的甲骨文总体估计，不是一个已找到、可直接导入的标准文件，更不是本站已完成的数量。** 不用现代汉字表、空编号或异体字凑到这个数字。

本批资料取得方式：

1. 小學堂古今字数据库甲骨文目录实际返回 **2,565 条目录记录**。按链接中的原生 `ZiOrder` 归并后为 **2,183 个字头号**，不能将 2,565 条都宣称为独立单字。
2. 对目录已出现的常规编号范围 1–1876 中缺失的 60 个号码，另用官方单字查询核对：取得 **50 个有实际字例的字头**，另外 10 个查询无字例，不生成条目。
3. 对已观察到的 3001–5952 范围中 2,585 个未收录编号逐项查询，全部取得实际字例，新增 **2,585 个来源字头及 2,585 幅字例**；每个新增分组先收一个来源字例，不宣称收全异体。
4. 原来的 12 个精选字例通过独立查询取得其字头号，合并进相同字头，不额外增加重复卡片。

网页的字头数和字例数由实际导入数据计算，不使用固定的“4,500”显示值。**4,818 个来源分组不等于已确认 4,818 个独立古字，超过约 4,500 的常见估计也不代表已经收全。** 原生字头号是这套目录的整理单位；不同字编与目录分组的关系、单字分合及全部覆盖范围仍有待研究，不按现代标签自行合并，也不宣称穷尽小學堂的所有资料。

小學堂另一个统计页列有 2,548 个字头、24,701 个字形；它与上述高级目录返回的范围和归并方式并不相同，不能直接用这个统计数作为本站完成量。

## 字形与说明来源

### 字形

直接保存[中央研究院小學堂](https://xiaoxue.iis.sinica.edu.tw/)字例页所指向的 PNG 图片：

- 字例页：`https://xiaoxue.iis.sinica.edu.tw/char?fontcode=<字例号>`。
- 字头页：`https://xiaoxue.iis.sinica.edu.tw/jiaguwen?ZiOrder=<字头号>`。
- 原始图片：字例页中的 `ImageText2/ShowImage.ashx`；新批次采用 200 点，原有 12 幅保留 300 点版本。
- 图片保留下载字节，不描画、不旋转、不平滑、不补笔，也不回退到现代字充当甲骨文。
- 每幅图有来源编号、著录、下载地址和 SHA-256。批量条目进行了页面字段对应及文件完整性检查；不把程序检查说成专家逐笔审校或逐例人工释读。

[小學堂版權聲明](https://xiaoxue.iis.sinica.edu.tw/License/License)将查询所得各解析度的「字形圖片」及属性信息以 **CC0 1.0** 提供。这个范围不是整套字体软件的分发许可；本站没有分发小學堂字体文件。

**字库图不是甲骨原拓；核对来源也不等于完成原片校勘。** 一个字例不代表该字全部异体。某条字形对应的隶定标签不能直接解释为所有卜辞中的词义。

### 辅助判断的材料

12 条记录另附[香港中文大学漢語多功能字庫](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/)相关字条。页面只交代材料讨论的主题、可访问的来源及引辞与当前图片的关系，不再给出本站版的定名、构件判断、读音或字源结论。当前并未取得逐字的完整研究证据链、原片上下文或系统的异说汇编，不能将这批链接宣称为充分论证。

例如，相关「止」字条引《合集》13688「疾止」，当前图片著录为甲1440、合31080。两者分开呈现，不把前者当作后者的配辞。普通话拼音仅作现代检索词保留在索引中，不展示为古字读音。

## 数据与维护

- `src/data/corpus.json`：按原生字头号归并的目录数据及字例来源记录。
- `src/data/catalogue.ts`：来源图片模型、原有精选内容合并、真实数量与稳定 ID。
- `src/data/curated-headwords.json`：原有 12 字的原生字头号；查询证据见研究目录。
- `src/data/glyphs.ts`、`source-manifest.json`：原有精选字例及相关文献入口、讨论主题和引辞边界。
- `src/data/modern-index.json`：120 个旧现代检索标签，辅助拼音与收藏兼容，不将其自行视作有甲骨字形的证据。
- `src/data/provenance.ts`：限定可显示的来源路径、编号和 URL；这是展示资格检查，不是古文字学鉴定器。
- `public/glyph-sources/sinica-corpus-20261031/`：本批来源 PNG，每个字例独立目录。
- `research/sinica-corpus-20261031/`：完整高级目录分页记录、各字例页面属性与原图。本地保存原始网页，GitHub 版本只保留许可范围内的属性摘录。
- `research/sinica-native-range-20261031/`：3001–5952 范围补查清单及新增字头的独立查询属性、图片和著录。
- `research/sinica-unlisted-headwords-20261031/`：常规编号缺项的独立查询、页面与图片；无字例的查询也保留记录。
- `research/sinica-curated-headwords-20261031/`：精选字例的字头号核对证据。

### 取得与导入

```bash
node scripts/collect-sinica-corpus.mjs "<项目根目录>" "<研究输出目录>"
node scripts/collect-unlisted-headwords.mjs "<项目根目录>"
```

取得脚本有限速，主目录最多两个工作线程；HTTP 错误即停止，不无限重试或补造数据。支持读取已经保存的研究快照续作。下载内容视为不可信数据，只读取，不运行其中脚本。自写脚本与下载目录分开。

导入必须等整批目录与补充清单完整，重新检查字例编号、页面图片、著录、PNG 与哈希，再复制到公开资源目录。已有资源只有字节相同时才复用，不覆盖变更过的图片。不得把 `checkedAt` 或测试通过当作学术准确性的证明。

### GitHub Pages

访问地址：https://asherethan.github.io/oracle-bone-academy/

`.github/workflows/pages.yml` 在 `main` 分支更新后自动安装依赖、运行数据与图片完整性测试、构建并发布 `dist/`，也支持手动触发。只发布构建产物，不把研究目录作为网站静态资源发布。使用固定提交的官方 Actions，部署权限仅赋予发布任务。

Vite 默认使用根路径 `/`，本地启动方式不变；工作流将 `VITE_BASE_PATH` 设为 `/oracle-bone-academy/`。字例图片的显示地址跟随这个前缀，但来源记录路径、编号与哈希不变；字体采用相对引用。可在本地复核项目子路径构建：

```bash
VITE_BASE_PATH=/oracle-bone-academy/ npm run build
VITE_BASE_PATH=/oracle-bone-academy/ npm run preview
node scripts/smoke-corpus.mjs "<项目根目录>" http://127.0.0.1:4173/oracle-bone-academy
```

以上环境变量写法适用于 Bash。在 Windows Git Bash 中，构建和预览命令前另加 `MSYS2_ENV_CONV_EXCL=VITE_BASE_PATH`，避免将 URL 前缀转换成 Windows 文件路径；GitHub Actions 的 Linux 环境不需要该设置。站点发布进度可在仓库 Actions 的 `Deploy GitHub Pages` 工作流查看。收藏仍保存在各自浏览器中；本地预览与线上站点的收藏不会互相同步。

## 技术、字体与隐私

React 19 · TypeScript · Vite · Lucide · Vitest · Playwright。纯前端，无密钥、无后端。图片与字体均本地托管，浏览时不向外部资料库发送请求；只有主动点出处链接时才前往来源网站。

标题使用本地 **Noto Serif SC** 子集，未覆盖的现代字标签回退到系统宋体。它不是甲骨文字体，许可为 SIL OFL 1.1，见 `public/fonts/serif/OFL.txt`。
